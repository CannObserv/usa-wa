# Modules — the roster-PDF source (#225, epic #219)

Layer 3, `packages/usa-wa-adapter-legislature/src/usa_wa_adapter_legislature/roster_pdf/`:
**source 2** of the WA Legislature adapter, split out of
[MODULES-LEGISLATURE.md](MODULES-LEGISLATURE.md) once the #226 write chain landed. The SOAP
half of the package is there; the tenure-span and operator-succession half is in
[MODULES-LEGISLATURE-SPANS.md](MODULES-LEGISLATURE-SPANS.md).

The WA Legislature's own *Members of the Legislature 1889-2025* roster PDF
(`usa_wa_legislature_roster`, 233pp, revision 2025-06-05). Its unique value is **102 years
below the WSL SOAP floor** plus the **exact mid-term succession dates** every live wire
structurally lacks, since spans are biennium-quantized.

They differ in kind, not just in endpoint: SOAP is a daily API, the roster is a **frozen
document revised about twice a decade**, so it is harvested quarterly, never joins the daily
refresh, and is never authoritative for the current biennium (it lags it by design).

## Phases

`harvest` (A) archives one edition · `cohort` + `normalize` (B) re-parse it offline ·
`audit` reads · `succession` → `resolve` → `backfill` write.

```
  roster_pdf/
    coverage.py   — one claim, `member_roster` **verified 1889-2025** — deliberately **CLOSED**, unlike every sibling feed. This source is a revision snapshot that cannot see past its own stamp, so an open-ended claim would assert coverage of a biennium it lags. Precedence: the roster wins for closed biennia below the WSL floor; operator events + WSL/SOS win at and above it
    transport.py  — `RosterPdfClient`: fetch + sha256. **No cache validators** on the response (no `ETag`/`Last-Modified`/`Cache-Control`, verified live), so change detection is a full GET + content hash — ~23MB/yr at the quarterly cadence. A **404 means re-discover the href** from the Legislative Information Center index, because `s4gf4suc` is a CMS-minted media key a re-publish is expected to rotate; any other status propagates, since treating a 500 as a rotated key would mask a real outage
    adapter.py    — `RosterPdfAdapter` (archive-only); `legroster:<revision-date>` keys off the document's own *Revision Date*, so the key means "this edition", not "this fetch". One key per revision is also the citation granularity (settled on #219): a 1943 row cites `legroster:2025-06-05`. **The revision is read from `resource_id` and then verified against the fetched document's own stamp** (CR finding 1): the key claims to name an edition, so the bytes must be that edition — otherwise the next published edition fetched under a stale `--revision` archives as the old one and every citation minted from it names an edition that never attested the fact. A disagreement raises `RosterRevisionMismatch` (→ harvest exit `4`, an operator re-runs with the new date); an unreadable stamp only warns. `normalize` raises
    extraction.py — the **single `pdfplumber` boundary**: bytes → word geometry (`extract_pages`) + the edition's own `Revision Date` (`extract_revision_date`). Its own module so `normalize` stays pure and both the adapter (which verifies what it archived) and the cohort provider (which re-parses offline) reach it without importing each other
    normalize.py  — **the parser, pure over word bounding boxes rather than text.** The layout defeats text extraction three ways — two columns per page, a year gutter the extractor treats as a separate cell, and annotations that wrap and can themselves end in dots + a party letter — so a naive line parse recovers **464 of 8,485 rows (5%)**. Rows reassemble by y-coordinate within an x-bounded column. Three shapes the real document forced: the **party token, not paren balance, terminates a row** (the source contains an unclosed paren at LD25 2021 that otherwise swallows the rest of the column); the **dot leader is optional** (a long annotation consumes it); and **year state threads across column and page breaks, per chamber** (#252): the state is a dict keyed by chamber, saved/restored at every divider crossing, because a page can interleave two blocks across its columns — the Senate block's tail in the right column's top above the House block's continuation — and a single scalar carried the wrong block's year onto a year-less successor row (C. W. Beck's 1974 appointment emitted as an 1899 senator). Two sibling #252 classes: a row that wraps *before* its dotted leader is held accumulating until the party token arrives (Newschwander's 1969 Senate term vanished; its debris glued onto an 1899 House row), and the footer band sits at 0.94 of page height — measured: content reaches 0.9205, the printed footer starts at 0.9646 — because 0.909 cut the bottom line of every full page (~60 printed rows, among them Frances Swayze, whose resignation the parse pinned on the wrong member). Known residual: one cluster-merged 1987 row (LD43, Niemi) still collapses its group into 1985. Section bounds come from the district banners, never a page range — districts run 1-60, so a fixed window truncates the tail. **Chamber is a full-width y-divider, not a page property** (#233): a district's Senate and House blocks routinely share one page — **35 of the 166 district pages** — so the chamber is resolved per row from the most recent `SENATE` / `HOUSE OF REPRESENTATIVES` banner above it, and crossing one resumes that chamber's own year sequence (fresh at the district's floor on first entry, #252). Reading it once from the running header filed every row below a mid-page banner under the wrong chamber, which is how the 1913 Socialist became a senator; because `Ind` folds to no party, that both invented an assignment and discarded a real one. Caught by the Brazier cross-check (#233), not by the audit oracle — whose match rate actually *improves* under the bug, since a Senate row covers a four-year term and a House row two, so mislabelled rows over-cover claims. Treat that rate as a floor on disagreement, never as a score to maximise. Party tokens are carried **verbatim**; folding an unknown one to `None` is the silent-drop bug #227 exists to prevent. **`_ROW_PARTY` is a closed alternation over `PARTY_TOKENS`, which relocated that bug one layer up** (#227 CR): a row whose abbreviation the source newly introduces fails the party match, fails the prose test, and was dropped by the silent-furniture branch — never reaching `unparsed`, so `usa_wa_common.parties`' `unknown_token` disposition could not fire from this path and #227's oracle reported a clean run over exactly the records that survived the parse. `_has_undeclared_party_tail` detects member-row *shape* (dot leader + short trailing token, one interior space so `Silver Rep.` qualifies, no dot runs inside the tail so a repeated leader resolves to its real token) and routes such a line to `unparsed` instead. Measured against the archived edition: **0 lines**, so it adds no noise and fires only on a genuinely new token. **Coverage is not total, by construction** (CR #59): the leader is optional in this source, so the threshold sits at two dots (measured identically clean to three, and the source does typeset `..D`) and the **13 of 4,601** token-terminated lines with no leader at all — 0.3% — remain invisible. A new abbreviation landing on one of those is still dropped; closing it needs a signal other than the leader. A conformance test pins `PARTY_TOKENS` ⊆ what the vocabulary can classify — it caught `Soc.` and the dotless `Ind` sitting in the unclassified bucket. Measured on the full document after #252: **8,584 records, 1889-2025, 53 districts, 1,046 annotated, 0 unparsed**
    provisioning.py — get-or-create the `usa_wa_legislature_roster` `Source` (`kind="document"`, archival retention, 90-day TTL) + seed its claim on both paths. A distinct row from the WSL SOAP source: same jurisdiction and target, different publisher and archive
    cohort.py     — **Phase B**, archive-first: `extract_pages` + re-parse **offline** from `RawPayload`. Load-bearing here more than anywhere — the parser is this source's riskiest component and will be revised, and re-running a revised parser must never mean re-fetching 5.7MB. "Latest" joins `RawPayload` and tie-breaks on the ULID event id (#82), so a payload-less re-fetch event cannot shadow the real edition
    audit.py      — **the read-only oracle** (#225 Phase 1), pure: partitions our own `(name, district, chamber, year)` claims into what the roster attests and what it does not. Unattested is a *candidate artifact*, never a deletion — below the roster's floor, absence is silence rather than denial. Matching folds honorifics/nicknames/initials via `usa_wa_common.names` (`Robert "Bob" McCaslin` ≡ `Bob McCaslin`), and a roster row **covers the term it opens** (`TERM_YEARS`: house 2, senate 4) — the roster lists a member only in the year their term *begins*, so exact-year matching marked ~half of all Senate claims unattested by construction. Live result: **2,064 claims, 98.0% attested**, and it independently reproduces both #144 findings with no hand-curation — Wynne's LD39 Senate 2001 flagged (the roster has him in the LD39 *House* only) while Marlo Braun's LD20 Senate 2017 is confirmed, dated to a five-day substitution a biennium-quantized span cannot express
    succession.py — **#226 read side**, pure: roster annotations → operator-event **proposals**, no writes. A proposal carries everything an `OperatorEvent` needs *except* the member id, which splits "what should we assert?" from "write it" so the emission can be inspected before a span moves. Two refusals rather than guesses: **day precision or nothing** (`Deceased July 1977` is real; rounding it invents the very kind of boundary this backfill exists to remove) and **a session reference is not a date** (`Appointed to serve 1951 2nd Ex. S.`, `Holdover from District 21, 1901 Session`). A House seat is **not** a third refusal (changed in #226's write half): the roster carries no Position, but it does carry the date, so an unpositioned House boundary lands in `report.unseated` — a proposal with `seat_kind='chamber-house'` and a `None` discriminator — rather than in `deferred`. Folding it into `deferred` discarded the kind, reason and date, which is what made 224 dated boundaries unrecoverable. A chamber move (`Resigned; Appointed to the Senate`) is `vacated`/`moved`, never `departed` — the member keeps serving, so closing every span would wrongly end their party tenure. A swearing-in beats the election date (service starts when sworn). **At most one start and one end per record**, both emitted (CR-2 finding 11): an annotation routinely states both, and returning a single outcome truncated 19 of them — including the Braun five-day substitution, where a `seated` with no end asserts the seat was held indefinitely, the ghost-open span #107/#119 exist to prevent. An appointment and its swearing-in are two dates for *one* boundary and collapse to the swearing-in. A **dateless** clause is skipped rather than fatal (CR-2 finding 10): `Appointed <external office>` carries no date and used to capture the seating branch, discarding 30 dated departures. Measured over the full document: **449 proposals / 224 unseated / 381 deferred** — `departed:resigned` 205, `seated:appointed` 122, `departed:died` 98, `seated:sworn_in` 24; unseated `seated:appointed` 177, `seated:sworn_in` 27, `vacated:moved` 20; deferrals `no_succession_verb` 244 (Speaker/Redistricted/Holdover/party-change — correctly not events), `no_day_precision` 137. All three carry the source page
    resolve.py    — **#226 write half, the identity step**, pure: a proposal states *what and when*; an `OperatorEvent` also needs *to whom* and *which seat*. Both come from corpora already on disk, with **two different floors**. *Which member* comes from the archived WSL sponsor roster (**1991**) — below it no `Person` exists at all, which is why 361 of 673 dated boundaries resolve to nobody: a coverage floor, not a parser failure. *Which House Position* comes from the existing House Position span corpus (**2003**, the #118 back-chain floor); below that #229 owns it. The surname match is scoped to one chamber+LD in one year — where at most two people sit — and uses the shared `usa_wa_common.names` token-set fold; a name matching two members of that seat is **ambiguous and refused**, never resolved by picking one (the corpus really does contain same-surname pairs in one district: two Hansens in LD13, two Kreidlers in LD22). **A surname match is not identity** (#240): the ambiguity check cannot fire when the row's true subject is *absent* from the index, and the single surviving match is then a **false** match rather than an ambiguous one. William A. Grant died 2009-01-04, before the 2009-10 sponsor snapshot, so the only `grant` in LD16 House was his successor Laura Grant-Herriot — whom WSL records under `LastName` `Grant` — and his death closed every one of her spans 18 days before she was appointed, silently disabling a correct operator attestation. The discriminator is the **given-name initial**, which must appear among the roster row's own tokens: every benign variant keeps it (`Mike`/`Michael`, `Moyne`/`Mike`, `J. Bruce`/`Jeffrey`, `C Louise`/`Louise` — a given name can itself be several tokens, so *any* of its initials matching is agreement), while two different people generally do not (`William` vs `Laura`). A heuristic, not a proof — a same-initial collision would still pass — and rejections report as `given_name_mismatch` rather than folding into `no_member`. It also **resolves** 5 boundaries previously lost to `ambiguous_member` (both Hansens, both Kreidlers, and Marlo Braun's five-day substitution), since a given name is exactly what separates a same-surname pair. **Two candidate years**, because a boundary outlives its row: `Deceased June 15, 1979` sits on a *1977* row. **The Position window reaches one year before the span** (`POSITION_LOOKBACK_YEARS`), and that is load-bearing rather than slop: a mid-biennium appointee is absent from the sponsor roster of the biennium they were appointed into, so their first span opens at the *following* one — Graham Hunt, appointed 2014-01-17, has only `ld-2-position-1:2015-16`. The span starting too late **is** the defect this backfill corrects, so requiring containment refuses precisely the events worth writing (measured: 236 → 253 resolved). The index answers "which Position digit", not "which span" — span selection stays with the overlay at apply time. Live: **258 resolved**, unresolved `no_member` 361 / `no_position` 52 / `given_name_mismatch` 1 / `ambiguous_position` 1
    backfill.py   — **#226 write half, the only writing module** (`python -m usa_wa_adapter_legislature.roster_pdf.backfill [--dry-run] [--limit N]`): resolved boundaries → `OperatorEvent` rows via `operators.store.record_operator_event`, stamped `entered_by='roster-pdf-backfill'` and cited to `…members-of-the-legislature-1889-2025.pdf#page=N` (the document is 233 pages, so a bare document URL is not a citation). **It defers to the operator everywhere the two overlap.** The store already held 124 hand-entered attestations and the roster independently reproduces **81 of them to the day** — strong corroboration, and also the hazard, so two refusals: an **already-attested** boundary is skipped (`record_operator_event` is idempotent on the natural key but still refreshes `reason`/`evidence_url`/`entered_by`, so writing one would replace a human's attestation with the machine's in a store whose premise is that provenance is never mutated, #54); and a boundary that **disagrees** with an attestation on the same tenure is skipped and *reported* — those 17 run from ±1 day (the roster dating a seating to the swearing-in where the operator used the appointment) to 41 days (Darneille), and writing them would leave one seat carrying two live non-superseded boundaries for the overlay to pick between. Conflict scope is the **tenure** — same member, kind, seat *and biennium* — so a gap-and-return member and a chamber mover both stay writable. A superseded row never blocks a write: a retracted boundary must not permanently veto the right one. A tenure holding **more than one** live attestation is all-or-nothing (CR-4): every disagreeing row is reported individually, and supersession requires *all* of them to be machine-entered — half-correcting would leave the tenure carrying two live boundaries anyway, having discarded the machine rows' evidence for nothing. The citation's base URL is read from the **archived `FetchEvent`**, not the compiled-in default: `s4gf4suc` is a CMS media key the transport already expects to rotate, and a citation pinned to the old URL dies the moment it does while the archived bytes stay good. Conflicts are logged one record each with `delta_days`, and the ledger counter is a **count**, not 17 nested bodies. `--supersede-conflicts` resolves the second case in the roster's favour, but **only against a machine-entered attestation** (`MACHINE_ENTERED_BY` — that allowlist *is* the flag's safety property; a named operator's attestation is never the backfill's to overrule). It is off by default because the safe reading of a disagreement is that someone knew something the roster does not. It was overridden once, on evidence: all 17 live conflicts were agent-entered rows citing Wikipedia/Ballotpedia, and **5 of the 9 conflicting departures had been dated to the successor's seating date** — collapsing "incumbent departed" and "successor seated" into one date and asserting a zero-day vacancy where 1–29 days actually elapsed (Johnson→Sumner 21d, Jesernig→Ludwig 29d, Barr→Morton 20d whose row even cited Morton's own page, Hale→Delvin 6d, Delvin→Brown 1d). Superseding **appends** and stamps the prior row's `superseded_by_id`, so the retracted attestation stays auditable (#54). Live dry run: **155 written, 17 superseded, 81 already attested**. **Deploy sidecar-paused** — every event moves a span boundary on the next builder re-drive, which re-anchors the PM Assignment; pause, run, re-drive the span builders, resume
    identity.py   — **#228 Phase 3b, the identity step**, pure: pre-1991 records → identities or refusals, zero silent drops. The identity fold strips what is not a name (position suffixes `– 19B`, parentheticals, quoted nicknames, honorifics — each class measured splitting a real person's tenure); grouping is fold **modulo checked-in adjudication tables** (5 spelling aliases, the `elmerejohnston` split, the 3 §3 join adjudications) with **no heuristic splitter** — the candidate same-year-different-seat rule measures as 44 chamber movers and ~0 impostors, because the roster indexes rows by *term-start* year. A >20-year consecutive-listing gap refuses with its subject named (14 groups). A fold crossing the 1991 floor joins the **existing WSL member**: seat-scoped surname match over the group's 1991+ rows → the #240 given-name-initial guard (whose failure mode inverts here: a false rejection mints a duplicate Person, the §2 fork) → year-corroboration tie-breaker (**≥2 distinct years and strictly ahead** — without the floor the rule accepts 1>0, the #240 shape) → adjudication. Corpus: partition exact (6,217 = identities + refusals), 108 joins, Galloway mints, zero join refusals
    party_changes.py — **#228 §4**, pure: the 22 change annotations in three families — year+token (18, incl. the paren-mangled Foss row; `Silver R` folds to the row vocabulary's `Silver Rep.` so #227's one resolver serves both), dated-with-party-unstated (3 — the new party is the member's *next listing*, which only the projector can see), prose (1). A change clause fitting no family returns `PartyChangeUnparsed` for the caller to tally — refuse, never guess. Corpus: 22/22 parse, 0 unparsed
    projector.py  — **#228 §4/§5**, pure: identities → the sponsor Phase B's own `Observation` shapes (`party`/`chamber-senate`), so the span builder consumes roster tenure exactly like wire tenure; a joined identity keys on its WSL member id, a minted one on its roster key. Senate terms expand per §5 (`min(term_start + TERM_YEARS, next_listing_on_seat) − 1`, clamped at the 1991 floor), with year→biennium quantization deferred to the term calendar; successor rows open (and predecessors close) at their annotation date's biennium; same-biennium handoff overlaps are **reported** (120), as are zero-coverage rows with a reason (10 — mostly members who died between election and swearing-in; the residue distinguishes a defect from a right answer). Party follows the seat coverage, split by §4 changes with the dated family inferring from the next listing; a #227-declined token withholds the party observation with its member attributed (§6). Corpus through `build_tenure_spans`: 9,569 observations → 3,775 spans (777 senate + 2,998 party), zero open, Landon exactly as §4
    harvest.py    — **Phase A** (`python -m usa_wa_adapter_legislature.roster_pdf.harvest --revision 2025-06-05`): archive one edition through `archive_only`. **One cohort, not a sweep** — the source publishes one document per revision, so re-running is a cache hit. A rotated key with no discoverable href exits `4` (`EXIT_DEGRADED`) rather than raising: the transport already tried to re-discover, so what remains needs an operator to re-point the source
```
