# Modules — the roster PDF's pre-1991 chain (#228)

Layer 3, `packages/usa-wa-adapter-legislature/src/usa_wa_adapter_legislature/roster_pdf/`:
the #228 half of the roster-PDF source, split out of
[MODULES-LEGISLATURE-ROSTER.md](MODULES-LEGISLATURE-ROSTER.md), which keeps the source
itself — transport, parser, audit oracle and the #226 succession read chain. Runbook:
[COMMANDS-ROSTER.md](COMMANDS-ROSTER.md).

These modules are pure. The build that drives them is the pipeline's conformed spans
(`usa_wa_pipeline.conformed.spans.roster_resolution` / `build_roster_spans`): resolve →
acceptance oracle → project → operator overlay, once per nightly. The Postgres builder and its
write side — `persons`, `emit`, `deepening`, `build` — were deleted in #412 PR F.

```
  roster_pdf/
    identity.py   — **#228 Phase 3b, the identity step**, pure: pre-1991 records → identities or refusals, zero silent drops. The identity fold strips what is not a name (position suffixes `– 19B`, parentheticals, quoted nicknames, honorifics — each class measured splitting a real person's tenure); grouping is fold **modulo checked-in adjudication tables** — which record the near-duplicate pairs adjudicated as *distinct* as well as the merges, since a near-duplicate sweep resurfaces them every time and the evidence is otherwise buried in the PDF (`nels`/`nils anderson`, `n. b.`/`n. p. atkinson`; pinned by a test so adding an alias for either has to fail) — (5 spelling aliases, the `elmerejohnston` split, the 3 §3 join adjudications) with **no heuristic splitter** — the candidate same-year-different-seat rule measures as 44 chamber movers and ~0 impostors, because the roster indexes rows by *term-start* year. A >20-year consecutive-listing gap refuses with its subject named (14 groups). **The floor is a *listing-year* floor but tenure crosses it (#259)**: the roster indexes a row by the year the term *begins*, so a fold with no post-floor listing still probes WSL when its term span reaches the floor (`year + TERM_YEARS[chamber] > floor` — exactly the 1989 Senate terms, which run through 1992). Measured: 16 members were minting duplicates of WSL Persons we already held, Patty Murray and Ellen Craswell among them. A fold crossing the 1991 floor joins the **existing WSL member**: seat-scoped surname match over the group's 1991+ rows → the #240 given-name-initial guard (whose failure mode inverts here: a false rejection mints a duplicate Person, the §2 fork) → year-corroboration tie-breaker (**≥2 distinct years and strictly ahead** — without the floor the rule accepts 1>0, the #240 shape) → adjudication. Corpus: partition exact (6,217 = identities + refusals), 108 joins, Galloway mints, zero join refusals. **`identity_seatings` (#226)** projects the resolved report back out as a `Seating` index for the succession resolver (no production caller since #412 PR F deleted the roster backfill) — one seating per record, keyed by `wsl_member_id` for a crosser and the minted `key` otherwise. Derived from the report rather than re-read on purpose: the member ids must be byte-identical to the ones the identity step minted, or an event lands on a person that does not exist. Refusals contribute nothing (a seating for one would seat a boundary on an identity we declined to mint). One seating per record *year*, not expanded to both years of the biennium the way the WSL loader expands: a proposal's `session_year` is always its own record's year, so expansion would only widen the same-surname collision surface. #277's `SEATING_ADJACENT_BIENNIA` is not in tension with that — it widens by whole bienniums on the *odd* (listing) years, which is where these seatings sit, and it ships with the whole-token guard precisely so the added candidates are split rather than pooled; measured, `ambiguous_member` went 4 → **0** as the window widened
```
