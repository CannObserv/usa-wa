# Modules — the roster PDF's pre-1991 build (#228)

Layer 3, `packages/usa-wa-adapter-legislature/src/usa_wa_adapter_legislature/roster_pdf/`:
the #228 half of the roster-PDF source, split out of
[MODULES-LEGISLATURE-ROSTER.md](MODULES-LEGISLATURE-ROSTER.md), which keeps the source
itself — transport, parser, audit oracle and the #226 succession write chain. Runbook:
[COMMANDS-ROSTER.md](COMMANDS-ROSTER.md).

```
  roster_pdf/
    identity.py   — **#228 Phase 3b, the identity step**, pure: pre-1991 records → identities or refusals, zero silent drops. The identity fold strips what is not a name (position suffixes `– 19B`, parentheticals, quoted nicknames, honorifics — each class measured splitting a real person's tenure); grouping is fold **modulo checked-in adjudication tables** — which record the near-duplicate pairs adjudicated as *distinct* as well as the merges, since a near-duplicate sweep resurfaces them every time and the evidence is otherwise buried in the PDF (`nels`/`nils anderson`, `n. b.`/`n. p. atkinson`; pinned by a test so adding an alias for either has to fail) — (5 spelling aliases, the `elmerejohnston` split, the 3 §3 join adjudications) with **no heuristic splitter** — the candidate same-year-different-seat rule measures as 44 chamber movers and ~0 impostors, because the roster indexes rows by *term-start* year. A >20-year consecutive-listing gap refuses with its subject named (14 groups). **The floor is a *listing-year* floor but tenure crosses it (#259)**: the roster indexes a row by the year the term *begins*, so a fold with no post-floor listing still probes WSL when its term span reaches the floor (`year + TERM_YEARS[chamber] > floor` — exactly the 1989 Senate terms, which run through 1992). Measured: 16 members were minting duplicates of WSL Persons we already held, Patty Murray and Ellen Craswell among them; `retire_unasserted_roster_persons` retires the rows an earlier run minted. A fold crossing the 1991 floor joins the **existing WSL member**: seat-scoped surname match over the group's 1991+ rows → the #240 given-name-initial guard (whose failure mode inverts here: a false rejection mints a duplicate Person, the §2 fork) → year-corroboration tie-breaker (**≥2 distinct years and strictly ahead** — without the floor the rule accepts 1>0, the #240 shape) → adjudication. Corpus: partition exact (6,217 = identities + refusals), 108 joins, Galloway mints, zero join refusals. **`identity_seatings` (#226)** projects the resolved report back out as a `Seating` index for the succession resolver — one seating per record, keyed by `wsl_member_id` for a crosser and the minted `key` otherwise. Derived from the report rather than re-read from canonical rows on purpose: the member ids must be byte-identical to the ones the mint wrote, or an event lands on a Person that does not exist. Refusals contribute nothing (a seating for one would seat a boundary on an identity we declined to mint) and the backfill logs them as `roster_backfill_identity_refused` so they read as adjudication work rather than as a coverage gap. One seating per record *year*, not expanded to both years of the biennium the way the WSL loader expands: a proposal's `session_year` is always its own record's year, so expansion would only widen the same-surname collision surface. #277's `SEATING_ADJACENT_BIENNIA` is not in tension with that — it widens by whole bienniums on the *odd* (listing) years, which is where these seatings sit, and it ships with the whole-token guard precisely so the added candidates are split rather than pooled; measured, `ambiguous_member` went 4 → **0** as the window widened
    party_changes.py — **#228 §4**, pure: the 22 change annotations in three families — year+token (18, incl. the paren-mangled Foss row; `Silver R` folds to the row vocabulary's `Silver Rep.` so #227's one resolver serves both), dated-with-party-unstated (3 — the new party is the member's *next listing*, which only the projector can see), prose (1). A change clause fitting no family returns `PartyChangeUnparsed` for the caller to tally — refuse, never guess. Corpus: 22/22 parse, 0 unparsed
    projector.py  — **#228 §4/§5**, pure: identities → the sponsor Phase B's own `Observation` shapes (`party`/`chamber-senate`), so the span builder consumes roster tenure exactly like wire tenure; a joined identity keys on its WSL member id, a minted one on its roster key. Senate terms expand per §5 (`min(term_start + TERM_YEARS, next_listing_on_seat) − 1`, clamped at the 1991 floor), with year→biennium quantization deferred to the term calendar; successor rows open (and predecessors close) at their annotation date's biennium; same-biennium handoff overlaps are **reported** (122), as are zero-coverage rows with a reason (9 — mostly members who died between election and swearing-in; both counts moved when the CR #75 year bound recovered Wilmer's typo-dated 1921 tenure, and the one `empty_horizon` is exactly the #252 LD43 residual). Party follows the seat coverage, split by §4 changes with the dated family inferring from the next listing; a #227-declined token withholds the party observation with its member attributed (§6). Corpus through `build_tenure_spans`: 9,569 observations → 3,775 spans (777 senate + 2,998 party), zero open, Landon exactly as §4
    persons.py    — **#228 write side, minting + retirement**: one Person per *minted* identity, natural-keyed `(usa_wa_legislature_roster, <identity key>)`; a joined identity mints nothing (a roster twin would be the §2 fork). Display name = the most recent listing's printed form, seat suffix stripped via the shared `identity.strip_position_suffix`; name parts stay `None` (decomposing one printed string is unattested inference). Idempotent — the §1 re-derivability property in write form, over **rows** not just keys: existing rows load in one keyed SELECT and a changed display name is refreshed (`renamed`), so a parse fix that corrects a printed form reaches the database
    emit.py       — **#228 write side, minted-member emission**: binds the generic span emitter with Persons *and* Assignments in the roster source space (the #79 PDC source-split precedent), Role resolution shared with the sponsor path (`resolve_span_role`, public since #228), and the single archived edition as every biennium's citation target — deduping to one Citation per Assignment, the honest shape when one document is the evidence
    deepening.py  — **#228, the standing sponsor-build input**: derives the WSL-joined identities' pre-1991 observations + the edition citation (lookup-only, `([], None)` on a fresh database). Called by every **unrestricted** `sponsors.build_spans` run — omitting it would re-assert the shallow 1991-start span keys and recreate the stranded rows the #97 collapse retires; the daily restricted path never derives (its cohort is all post-1991). The extras' bienniums are also the *scope* of the emitter's `fallback_citation` (CR #85): the edition attests what it contributed, never a biennium the sponsor archive merely lacks. Each call re-parses the edition and re-resolves the corpus (~seconds, uncached, operator-only callers)
    build.py      — **#228 Phase B builder CLI** (`python -m usa_wa_adapter_legislature.roster_pdf.build [--dry-run]`): parse → resolve → **acceptance oracle** → mint → **operator overlay** → emit + cite → **retire** → deepen. The overlay step is #226's: every pre-1991 span is this builder's, so the roster's dated mid-term boundaries take effect here or nowhere — `apply_operator_events` between `build_tenure_spans` and emit, then `cite_operator_events` so each moved boundary carries a field-level citation to the attestation that dated it (#54). Events are loaded scoped to this build's own members (matching is by `member_id` regardless, so an unscoped read pulls thousands of WSL-era rows to apply none), and `operator_cites` — not `operator_events_loaded` — is the applied count. The hard oracle runs before any write: partition exactness (every pre-1991 record in exactly one identity or refusal), person-side Senate simultaneity in one *session year* (the one invariant nothing downstream checks), unrecognized party tokens abort; refusals/declines/uncovered rows are tallied outcomes, never aborts. `retire_unasserted_spans` then soft-deletes roster spans this derivation no longer asserts (CR #86 — the pre-1991 rows are emitted closed, so the #83 open-row sweep cannot see them go stale). Every tally reaches `counters` — *derived* from the summary, so the durable #178 ledger record cannot fall behind it. A tripped guard on either sweep, or an anchored stranding the sweep left for the #97 collapse, exits `4` (degraded), never a silent `0`. Prod-verified (rolled back): 2,494 Persons, 3,627 roster Assignments, 933 deepened, refusals wide_gap 14, declines 2, uncovered 9, overlaps 122. **Deploy sidecar-paused** with the `sponsors.migrate_spans` collapse (130 anchors transferred, 0 orphans) — the sequence is in COMMANDS-ROSTER.md
```
