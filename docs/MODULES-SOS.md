# Modules — WA Secretary of State adapter

Layer 3, `packages/usa-wa-adapter-sos/`: the multi-source target package that
owns the WA House Position seat — one source subpackage per SOS feed plus the
source-agnostic `house/` application. The pattern it follows is in
[ARCHITECTURE.md](ARCHITECTURE.md).

```
  usa-wa-adapter-sos/                 — Layer 3: **everything WA Secretary of State** — House Position **authority** (#100/#101). Follows the multi-source target-package pattern ([`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md)): one **source** subpackage per SOS feed (each a self-contained archive), the `house/` **application** source-agnostic. Since the #101 re-partition this package **owns** the WA House Position seat: WSL drives membership (who sits), SOS drives the ballot Position 1/2, the seat is emitted `usa_wa_legislature`-sourced (symmetric with the Senate seat, #75), and PDC is demoted to the `person_wa_pdc` identifier link. The `house/` composition root imports WSL + PDC; WSL/PDC never import SOS

      coverage.py     — **the two SOS feeds' declared coverage claims** (#180), and where `absent` earns the schema: filings `election_year` **verified** 2008–2018 *plus* **absent** 2020→open (the Power BI retirement — `electionDate=202011` → HTTP 500, probed live 2026-08-06 — which lived only as prose in ARCHITECTURE.md, so "does any source cover 2020?" was rediscovered by running a harvest into a 500); results `election_year` **verified** 2008→open, no gap. That asymmetry is why this package holds two sources, and it is now queryable rather than inferred from two docstrings. Both harvests' floors and the filings **ceiling** (#169) derive from these claims
      provisioning.py — get-or-create the **two** SOS `Source` rows (+ seed each feed's coverage claims, #180): `get_or_create_source` (`usa_wa_sos`, filings) + `get_or_create_results_source` (`usa_wa_sos_results`, results); both archival retention
      senate_corroboration.py — the **SOS Senate consumers** of the odd-year `senate_winners()` cohort (#123 §2, `python -m usa_wa_facts_seats.senate_corroboration`; daily 07:00 timer). The Senate seat is WSL-sponsor-built (`usa_wa_legislature`); SOS only consumes its ballot evidence, so this lives SOS-side (SOS→legislature, never the reverse — the `house/` layer). **2a** `cite_elected_senators`: field-cites each elected senator's open span `valid_from` to `sos-legresults:<odd>` via `add_field_citation` (attestation, **not** a boundary move — the Nov win doesn't move the operator-dated June appointment; Hunt). **2b** `missing_winner_lds`: an odd-year winner with **no open `state_senator` seat** at that LD is a silent missing operator `seated` (the asymmetry the chamber-count gate only catches post-drift) → named + exit 1 → operator email. A surname-mismatched occupant is surfaced (`mismatched_lds`) but not cited/failed; no odd cohort = clean no-op. App-role DML (idempotent Citation insert)
      house_corroboration.py — the **House sibling of `senate_corroboration` 2b** (#149, `python -m usa_wa_facts_seats.house_corroboration`; daily 07:05 timer). A House odd-year **special** winner who never materializes into a `state_representative` Position seat was caught by nothing (the LD30 Pos 2 2015-16 / Teri Hickel case: won the Nov 2015 special, archived + rostered, yet sat unseated because the backfill wasn't run and the daily refresh is `restrict_to_biennium=current`; found by manual audit). `corroborate_house_winners` consumes the odd-year `house_winners()` cohort (winners-only — a *loser* candidacy must never false-match) and `missing_house_winner_seats` asserts every `(LD, position)` a special decided has an open seat → named + exit 1 → operator email; a surname-mismatched occupant is `mismatched_seats` (surfaced, not gated — the seat-existence-not-identity rule). **Read-only, no 2a citation half** (the House Position spans already cite the odd wire in `house/build.py`). Keyed on `(LD, position)` not LD (two seats/LD). `--sweep-biennia` is the #119 **report-only** point-in-time historical audit (every archived odd year vs the occupancy that covered it, exit 0 unless `--strict`) — the LD30-as-history regression the current-biennium daily gate can't reach
      filings/        — **SOURCE 1**: votewa `ExportToExcel` candidate filings (`usa_wa_sos`, 2008–2018; SOS retired it to Power BI for 2020+). Its own archive; unique value = candidacy metadata (`Email`/`FilingDate`/`IsWithdrawn`, #99). No longer drives the seat (results does) — kept per *yes-and*

        adapter.py    — `SOSAdapter` (source_slug `usa_wa_sos`, **archive-only**); `sos-whofiled:<YYYYMM>` keys; `normalize` raises
        normalize.py  — filings-CSV → `{LD: [HousePosition]}`: `house_position_qualifier`/`filing_ld`/`build_house_filings` (`HouseFiling` is a back-compat alias of the shared `HousePosition`)
        cohort.py     — `SosFilingCohortProvider` (archive-first `{year: {LD: [HouseFiling]}}` + `citation_events`, joins `RawPayload` #82, memoized)
        harvest.py    — **Phase A** (`python -m usa_wa_adapter_sos.filings.harvest`, floor 2008, **ceiling `DEFAULT_ELECTION_CEILING = 2018`** — the Power BI retirement, so the bare invocation no longer walks off the 2020+ cliff; an explicit `--to-year` past it is still honoured, #169): sweep even years → archive `sos-whofiled:<YYYYMM>` via `archive_only`. **Per-year resilient** — each year in its own SAVEPOINT, an `httpx.HTTPError` (status *or* transport) is `cohorts_skipped` while *reached* years commit, a DB error still aborts; all-skipped fires the distinct `sos_harvest_total_outage` warning. One tally, no absent/skipped split (no per-year filename discovery, so no `LegislativeExportNotFound` analogue). `--pause-seconds` defaults to `None` (unset leaves `USA_WA_SOS_MIN_REQUEST_INTERVAL` in force) / `--dry-run` / `--force`
      results/        — **SOURCE 2**: `results.vote.wa.gov` legislative election results (`usa_wa_sos_results`, 2008→present incl. the current cycle; **the seat's Position source since #101**). Unique value = ballot Position **+** vote counts, current-cycle coverage the filings export can't serve
        transport.py  — `SOSResultsClient`: `general_election_date(year)` (YYYYMMDD = first Tue after first Mon of Nov), **traverses `export.html`** to discover the Legislative CSV href (filenames vary — 2012 carries a certification timestamp), redirect-follows to the lowercase path → `WireFetch` (#54) + `parse_legislative_results` (#56). `LegislativeExportNotFound` vs `httpx` errors are the harvest's two skip signals; own limiter env `USA_WA_SOS_RESULTS_MIN_REQUEST_INTERVAL`
        adapter.py    — `ResultsAdapter` (source_slug `usa_wa_sos_results`, **archive-only**); `sos-legresults:<YYYYMMDD>` keys; stamps the `export.html` anchor onto `FetchEvent.url`; `normalize` raises
        normalize.py  — **robust race-label parser** (the #101 audit): office+LD+position live in one `Race` string, labelled **three** ways (`State Representative Pos. N` ~99% / `Representative, Position N` at 2020 LD15 / bare `State Representative N` at 2014 LD30 — sometimes differing between one district's two seats). Rule: a `Race` naming a *Representative* (not *Senator*) → LD after `DISTRICT` + the **trailing** `1/2`; `WRITE-IN` dropped. `build_house_positions` → `{LD: [HousePosition]}`. An exact-string parser silently drops real seats — never do that (see ARCHITECTURE.md). Also **`parse_senate_race`/`build_senate_winners`** (#106 A′; Senate labels **audited clean 2008→2025** at #123 — one `Legislative District N - State Senator` shape, case-insensitive, zero variants) — the Senate half of the same wire the House parser drops: `{LD: SenateWinner}` (the top-`Votes` non-write-in candidacy per LD; a vote tie / unparseable multi-candidacy LD is omitted, never guessed). The Senate seat is unqualified, so this is **attestation** (an elected senator's ballot line) not structure. **`build_house_winners`** (#123) is the House sibling — the winning candidacy **per (LD, position) race** (the odd-year merge filter, hazard b); it + `build_senate_winners` share the never-guess `_top_vote_winner`
        cohort.py     — `SosResultsCohortProvider` (archive-first `{year: {LD: [HousePosition]}}` + `citation_events` + **`senate_winners()` `{year: {LD: SenateWinner}}`** #106 A′ + **`house_winners()`** #123 (the odd-cohort **winners-only** House map — `build_house_winners`, the merge input) — joins `RawPayload` #82, memoized) — the **seat builder's** cohort
        harvest.py    — **Phase A** (`python -m usa_wa_adapter_sos.results.harvest`, floor 2008): sweep **every** general-election year (odd years included, #106 — a WA general runs each November and an odd-year special seats legislators, e.g. Hunt LD5 Senate Nov 2025) → archive `sos-legresults:<YYYYMMDD>`. Sweep bound derives from `election_years_for_biennium` (the shared #106 helper); default `--to-year` = current calendar year (not the biennium's seating year, else the odd cohort is missed). **Per-year resilient** — an HTTP 404/500 year is `cohorts_skipped` (only this raises the whole-source outage warning) and a **no-legislative-race** year with no CSV (2021/2023) is the expected `cohorts_absent`, each rolled back in its own SAVEPOINT while *reached* years commit; `--pause-seconds`/`--dry-run`/`--force`. **Exit `0`/`1`/`2`, plus `4` (`EXIT_DEGRADED`) when EVERY year is skipped — new at #179b** (CR #196 finding 22): the outage was detected and logged as `results_harvest_total_outage`, and the CLI still returned `0` — a warning with no consumer, which is the failure `clearinghouse_core.runs` (#178) exists for and names *this module* as its worked example. The sibling `filings.harvest` already exited `4` for the identical condition, so this brings the two halves of one source into line. The test is skipped-vs-total, not `archived == 0` (`archive_only` returns False on a cache hit); an **absent-only** sweep is not degraded, and `degraded` still commits the reached years. `expected_years` (#201) names the years whose HTTP failure is a WARNING — the daily refresh passes only the seating year, so the not-yet-certified odd cohort's miss stays INFO
        archive_refresh.py — **the DAILY Phase A** (`python -m usa_wa_adapter_sos.results.archive_refresh`, #201, slug `sos-archive-refresh`, unit `usa-wa-sos-archive-refresh.service`): archive the current biennium's cohorts — both generals its membership can be decided by (`election_years_for_biennium`, #106) — through `harvest_results(force=True)`, so each lands in its **own SAVEPOINT** (an odd cohort 404s from January until that November is certified, and a race-less year has no CSV; skipped-and-logged at INFO, the seating cohort still archives) and the day's archive is the day's wire. Exit `4` when *every* cohort was unserved. **This half used to run inside the fact's `refresh.py`** — the reason `usa-wa-facts-seats` carried an `import-linter` exception for a transport import; the fact now rebuilds only. `USA_WA_BIENNIUM` scopes it (non-current → `sos_archive_refresh_noncurrent_biennium`)
      house/          — **APPLICATION**: the WSL+SOS House Position seat (#101), **source-agnostic** (consumes a cohort provider). WSL owns membership (who sits), SOS the ballot Position; emitted `usa_wa_legislature`-sourced (symmetric with the Senate seat, #75). Imports WSL + PDC; WSL/PDC never import SOS
        projector.py  — **pure** `build_house_seat_observations(house_roster, positions_by_ld, biennium)`: join the sitting WSL roster to the SOS positions (`position_for`) → `chamber-house` `Observation`s keyed on `ld-{n}-position-{p}`. No resolvable position → emit nothing, `missing_position` (OQ1: post-1965 unknown = data gap, not a position-less `state_representative`; the pre-1965 at-large seat is power-map#302) — **unless within-LD elimination (#103) resolves it**: exactly 2 sitting members + exactly 1 ballot-claimed seat + exactly 1 unmatched member → the remaining position is theirs (seats a mid-biennium appointee — Obras/Salahuddin — and heals a ballot↔roster name change — Caldier→Valdez, McCabe→Mosbrucker — alike; no party constraint, the position is the seat). Inferred pairs tracked in `inferred_keys` + `summary["inferred"]` (the PDC #74 precedent); guardrails decline a 3-member roster (a named predecessor still claims their seat — sequential occupancy), a double-unmatched LD, and the pre-2008 era. **`seed_positions` (#118)**: a Position back-chained from a later biennium's anchor seats an otherwise-unmatched member rostered in that LD (roster-cited, joins `inferred_keys`; also tracked in `seeded_keys`) and feeds the elimination like a ballot-claimed seat — ballot always wins over a conflicting seed
        build.py      — **Phase B** (`python -m usa_wa_facts_seats.house.build`): the builder — reads the WSL sponsor archive + the **results** cohort offline, projects per biennium, merges into `TenureSpan`s, emits one `usa_wa_legislature` `state_representative` Position Assignment per tenure (`emit_house_position_spans`, cite-every-biennium onto `sos-legresults:<Y>`), then `close_stale_spans(usa_wa_legislature, {chamber-house})`. **Odd-year merge (#123 §1)**: the biennium's position map is `even_seating(S-1) ∪ odd_special_winners(S)` (`_merge_positions`, driven by `election_years_for_biennium`) — the odd November special ballot seats an appointee (Obras/Salahuddin) **directly** (matched, not #103-inferred), the even cohort keeping its full candidacy set (the elimination needs the losers) while only the odd side is winner-filtered (`house_winners`, hazard b). Merged **before** the `restrict_to_biennium` filter so a cross-boundary member still builds ONE deep span (hazard d, #100-CR). `special_keys`/`special_events` cite the odd wire for a member resolved from the odd cohort (hazard c — the `inferred_keys`/`roster_events` precedent). An **inferred** (member, biennium) (#103) cites the sponsor roster `sponsors:<biennium>` instead (the wire that names an appointee) + logs `house_seat_inferred`. **One builder for daily + historical** (`restrict_to_biennium`=current vs `None`) → a cross-2018 member builds the same deep open span either way, so the #100 CR finding-1 depth mismatch **cannot recur**. Coverage 2008→present directly, extended back to **2003-04** by the #118 back-chain (`backchain.py`, `--max-backchain-hops`); the 1991-2001 map-era stays uncovered (no reachable anchor across the 2002 break, #140). Depends on #77 (Persons + sponsor archive) + the results harvest. **Historical backfill: sidecar-paused, same window as the migrate** (`--biennium` scopes to a biennium's current members; `--dry-run`) — and since #118 back-chain runs in the **daily** path too, deepening a long-tenured current member's span re-keys its `source_id` start, so the migrate's #103 superseded-collapse must run in the deploy window even for a daily-only rollout, else the deepened row orphans the old anchor. **Roster hygiene (#105)**: each biennium's roster sheds mover rows (the `build_house_roster` Id exclusion) + committee-corroborated stale rows (`sponsors.roster_hygiene`, `--stale-min-coverage`) before projection — un-blocking the #103 elimination in ghost-inflated LDs and letting the sweep close the ghosts' seats. **Chamber-move overlay wiring (#145)**: `keep_ids` here is `stale_exempt_members(events, biennium) − house_mover_ids(biennium)` — an operator-touched **non-mover** is kept (built for a `vacated` to date) but only **through their latest event biennium** (biennium-scoped, #145 CR — a later committee-stale ghost like a defeated member is not kept, so their span isn't stretched past their real departure), while an operator-touched **mover** is deliberately NOT kept (re-including one re-runs the #103 elimination and splits the backfiller into superseded `:YYYY-YY` duplicates — the reverted 2013-14 tranche). The per-biennium `movers_by_biennium` map (`pdc_matching.house_mover_ids`) is passed to `apply_operator_events`, which **synthesizes** the mover's CLOSED House tenure from the `vacated` instead — zero superseded rows, no `house.migrate`, no PM anchor churn
        backchain.py  — **pure** #118 back-chain orchestrator (`backchain_house_observations`): walks the archived biennia newest→oldest and carries each **ballot-class** member's Position (ballot-matched hop 0, or its own back-chain seed hop k) back one biennium at a time (seeding `build_house_seat_observations`), so a pre-2009 biennium below the SOS floor is seated from a later ballot + the #103 elimination cascade. Reaches the 2001-map era's pre-2009 biennia (2003-04→2007-08). Guardrails: `REDISTRICTING_ERA_START_BIENNIA` breaks (WA keeps LD numbers, so the break is *explicit*, not a discriminator change), an LD-move / tenure-gap break (the projector only applies a seed to a member rostered in that LD), and `MAX_BACKCHAIN_HOPS_DEFAULT` (4). **Phase 1 carries back only ballot-class positions** — an elimination-only mate is emitted but does not recursively seed its own tenure (the deeper cascade is Phase 2, deferred to bound false positives — a wrong hop asserts a false structural seat). Pure; runs inside the ONE builder before span merging, so daily + backfill share span identity
        emit.py       — `emit_house_position_spans`: bind the spans to the generic `span_emit` — WSL Person + get-or-created `state_representative` seat Role (per `(LD, Position)`, resolved from the span discriminator), Assignment `source` defaults `usa_wa_legislature`, cite-every-biennium onto the driver cohort — an `inferred_keys` biennium onto `roster_events` (#103). Reuses PDC's seat-Role source-id/discriminator helpers (one-directional Layer-3 sibling import)
        migrate.py    — one-shot **owner-role** #101/#103 migration (`python -m usa_wa_facts_seats.house.migrate`), run **after** `house.build`, two passes: **(1)** the #103 within-source superseded collapse FIRST — elimination deepens tenures, so an anchored `usa_wa_legislature` row superseded by a deeper-start row of the same seat collapses onto it (`_superseded_pairs`, the #97 pattern; `superseded_retired`; disjoint tenures stay; a keeper that merged in place keeps its own anchor → the superseded one is dropped + warned, #80); **(2)** retire existing `usa_wa_pdc` 4-part chamber-house rows onto the covering **surviving** `usa_wa_legislature` span. **Covering-window collapse, not an exact-`source_id` re-point** — the old PDC span is *shallow* (pre-#101, 2018+ positions) while the new WSL+results span is *deeper*; map by `(person, role)` + validity window (`_covering_span`/`_retire_onto` #91/#97), transfer the PM anchor, delete the row + its citations (so the sidecar can't mint a duplicate PM assignment). No covering keeper → `orphans_no_keeper`; 3-part legacy → `skipped_legacy` (`migrate_pdc_spans`'s job). **Sidecar-paused, same window as the harvest + build, before anything drains to PM.** Idempotent; `--dry-run`
      raw_harvest.py (package root) — **#302 raw-tier harvest** (#304, `python -m usa_wa_adapter_sos.raw_harvest`, slug `sos-raw-harvest`): both SOS sources one run — WhoFiled filings + legislative results per decisive year, written as pristine wires to `raw/usa_wa_sos/` + `raw/usa_wa_sos_results/` under the archive's resource ids; per-cohort and per-source failures contained. Runs beside the Postgres tier until #302 cutover
        refresh.py    — `python -m usa_wa_facts_seats.house.refresh` (#101): the **daily** driver of the House Position seat, **rebuild-only since #201** — re-drives `build_house_position_spans` scoped to the current biennium off the archive, and archives nothing (that is `results/archive_refresh.py` above, its own unit ordered before this one; splitting them is what let the `import-linter` exception go). Runs **after** the WSL refresh (reads its sponsor archive + binds its Persons); independent of the PDC refresh. Systemd timer 06:45 UTC fires this unit, which `Wants=` the archive half — weak on purpose: on a votewa outage the seat still re-derives from the last good archive rather than being cancelled with it
```
