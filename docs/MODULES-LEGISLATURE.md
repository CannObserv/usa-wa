# Modules — WA Legislature adapter

Layer 3, `packages/usa-wa-adapter-legislature/`: the WSL SOAP source mapping —
transport, normalizers, the daily refresh, cohort providers, probes, and the
Phase-A harvests. The tenure-span and operator-succession half of the same
package is in [MODULES-LEGISLATURE-SPANS.md](MODULES-LEGISLATURE-SPANS.md).

## Package layout (#183)

The Washington State Legislature is **one target publishing one `Source`**
(`usa_wa_legislature`), so `docs/ARCHITECTURE.md`'s `<source_a>/ <source_b>/`
split has nothing to divide here — the package top level *is* the source. What
it does have is four distinct **archives** under that one Source, each with its
own SOAP service, resource-id scheme, normalizer, cohort provider and harvest.
Those are the subpackages; before #183 all 48 modules sat flat in one namespace
and a filename told you nothing about which archive it touched.

| Directory | Archive key | SOAP service |
|---|---|---|
| `sponsors/` | `sponsors:<biennium>` | `SponsorService.GetSponsors` |
| `committees/` | `committees-roster:<biennium>` | `CommitteeService.GetCommittees` |
| `membership/` | `committee-members-hist:<biennium>:<id>:…` | `CommitteeService.GetCommitteeMembers` |
| `meetings/` | `committee-meetings:<begin>:<end>` | `CommitteeMeetingService` |
| `operators/` | *(no wire)* — the `usa_wa_operator` attestation Source | — |

Inside each, the module names are `docs/ARCHITECTURE.md`'s own vocabulary:
`transport` / `adapter` / `normalize` / `cohort` / `harvest` for sourcing, and
`projector` → `build` → `emit` → `migrate_*` for what is derived from the
archive. `harvest.py` is always **Phase A** (archive the wire) and `build.py`
always **Phase B** (spans from the archive) — the distinction the old
`harvest` / `harvest_sponsor_spans` pair hid behind a plural.

What stays at package top level is what serves every archive: `transport.py`
(one wire), `adapter.py`, `provisioning.py` + `coverage.py` (one `Source`, its
claims), `cohorts.py` (the public provider seam), `bootstrap.py` / `synthesis.py`
(the anchors), `normalize/`, `refresh.py` (the daily driver) and
`migrate_role_types.py` (re-stamps Roles written by two families).

      meetings/harvest.py — backfill CLI (#39): sweep a biennium range through the runner (archive wire + upsert org_type='other'), then freeze the deduped cohort to the seed + seed_manifest sidecars. Closed windows = cache hits on re-run
      committees/ingest_seed.py — no-WSL seed loader (#39): verified_digest gates the bytes → synthetic FetchEvent.content_hash + archived RawPayload, fill-only upsert (seed is a floor, not an authority)

Best-effort in its own SAVEPOINT, and gated to the date-current biennium (a backfill pin's spans are the `sponsors.build` CLI's job). Hunt `35410`) and a boundary mover / departed member carries a **name-blanked stub** (`"Representative "`/`"Senator "`, null name/district/party — Orwall/Slatter House stubs, departed Hawkins/Hunt/Rivers). `is_person` filters the blanked stubs; the sponsor normalizer iterates rows and dedups Person by `Id`. The non-archival transport pulls it uses — `get_sponsors` / `get_active_committee_members` — are the parsed-dict siblings of `get_committees` (archival `fetch_*` forms land in step 1)

No seed frozen (deferred). `--dry-run` rolls back
      committees/cohort.py — `CommitteeRosterCohortProvider` (Phase B): biennium → `{source_id: LongName}`, **archive-first** (re-parses the archived `committees-roster:<biennium>` wire offline via `parse_committees`; live GetCommittees fallback only for an un-archived biennium). `archived_bienniums()` enumerates the chain's domain. The roster analog of `meetings/cohort.py` (#56)
